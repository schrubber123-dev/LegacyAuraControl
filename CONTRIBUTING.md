# Contributing

Contributions and hardware reports are welcome.

## Hardware reports

For a new laptop model, please use the **Hardware compatibility report** template and include the diagnostics copied from the application.

## Code changes

Please keep changes focused and do not add proprietary ASUS binaries, SDK files, firmware, drivers, logos, artwork, or other material you do not have the right to redistribute.

By submitting code or assets, you represent that you have the right to contribute them under the project's MIT license. Compatibility/product names should be used only where needed to identify supported hardware or software.

The most important rule is **do not break confirmed GU501GM / PID 1866 support**.

## Pull requests

A useful pull request should include:

- a short explanation of the change
- hardware model used for testing
- whether RGB effects still work
- whether brightness still works
